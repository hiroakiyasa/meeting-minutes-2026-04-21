## 🔍 3スキル スペック比較

| 観点 | 01 Elite | 02 Automation | 03 Creative |
|---|---|---|---|
| **設計思想** | ミニマル・1スライド1メッセージ | 情報を漏らさず構造化 | 見た目で記憶に残す |
| **配色** | 黒・白・Apple Blue (#0071E3) | ネイビー・水色・白（堅実） | 珊瑚赤・黄・ティール・クリーム |
| **タイポ** | Helvetica Neue 大型（最大84pt） | 游ゴシック 中型（日本語最適化） | 極端コントラスト（140pt〜11pt） |
| **レイアウト** | 対称・極端余白 | グリッド・箱組み | 非対称・大胆色面 |
| **情報密度** | 低（スライド数多い） | 高（1枚に集約） | 中（ビジュアル優先） |
| **日本語適性** | △（英字フォント想定） | ◎（游ゴシック指定） | ○（英字混じり） |
| **適用シーン** | 経営層向けピッチ・対外プレゼン | 社内議事録・報告書 | ブランド資料・採用広報 |
| **印刷適性** | △（大面積の黒） | ◎（白基調） | △（色面多い） |
| **アニメ想定** | 強（Push/Fade） | 弱（静的） | 中（Zoom/Reveal） |

## 🎯 どれを選ぶべきか

### 用途別の推奨

| あなたの状況 | 推奨 | 理由 |
|---|---|---|
| 経営層・役員への**プレゼン資料** | **01 Elite** | インパクト重視、読ませない見せる |
| 社内で**正式議事録として配布** | **02 Automation** | 情報を漏らさず、保存性・検索性が高い |
| 社外への**広報・ブランド資料** | **03 Creative** | 記憶に残る、差別化される |
| 日本語で**画面共有しながら説明** | **02 Automation** | 游ゴシックで読みやすい |
| **印刷して配布** | **02 Automation** | 白基調でトナー消費少 |
| **AI/テック系のキーノート** | **01 Elite** | Tesla発表会のような空気感 |

### ワークフロー別の推奨

- **議事録を毎週作る定型業務** → `02 Automation`（テンプレート反復に強い）
- **投資家・大口顧客向け一発勝負** → `01 Elite`（最高品質1本を磨き込む）
- **採用・マーケ広報** → `03 Creative`（ビジュアルアイデンティティ）
